# 标定与实机验收

## 先确认硬件

1. 选择与硬件对应的 PlatformIO 配置，确认外部电源为稳定 5V，负载启动时不会掉电复位。
2. 暂时不接连杆，断开振动模块，逐个用磁铁检查霍尔。发送 `s`，全开 H1=1、H2=2、H3=4。XIAO 另有 H4=8、H5=16。
3. 程序一上电会归位。无磁铁到达 H1 时约 3 秒进入 `fault=2`，应观察到 N20 停止或 SG90 取消脉冲；不会自行无限重试。
4. 用串口 `r` 重试前先排除机械卡阻。此操作会重新预热、清除连续异常计时。

## 舵机 / N20

Nano 的 `servoOpen`、`servoClosed` 均在 `firmware/config.h`。可反向设置，例如开 150°、闭 30°，控制核心会相应改变角度方向。角度应保守限制在不会卡死的区间。启动时若霍尔已有效，程序以对应的标称角度开始；无霍尔时从开闭范围中点命令向全开方向搜索。SG90 是位置舵机，上电首次角度命令仍可能引起明显运动，首次标定应脱开负载。

每 20 ms 最多改变 1°，检测到目标霍尔后保持当前命令角度，不再继续走到标称角度。因此连杆实际位置由霍尔确认，不是仅靠估算运行时间。正常到位保持舵机输出以支撑负载；故障时 detach 解除驱动。Detach 不等于断开舵机电源，外力可能使机构移动。

Nano H1/H2/H3 对应三档；不能用三个传感器声称获得五个独立实测位置。XIAO H1～H5 对应五档。磁铁触发区不应重叠，多霍尔信号首次出现就暂停输出，持续 20 ms 锁定冲突故障。

闭眼方向经过的传感器编号必须增大，开眼时必须减小。若反向经过，锁定 `fault=3`。找不到目标则 `fault=2`。禁止为了掩盖卡阻而大幅增大超时。

## MQ135

初次使用的预处理 / 老化时间按实际传感器资料执行；固件每次启动的 3 分钟预热不代表完成首次老化，也不保证所有模块已稳定。

串口 `raw` 是 ADC 原始值；`air_index` 是 ADC 经过 1/8 平滑后线性映射至 0～2000。它不是 ppm，也没有套用未经校准的 MQ135 转换公式。Nano 的 ADC 满量程 1023，ESP32 配置为 4095；分压与两板的 ADC 特性会使实际指标不同。

先在空气良好且传感器已稳定的环境记录基线与波动，再观察通风前后变化，设置 `highThreshold`、`resetThreshold`、`levelThresholds` 与 `levelHysteresis`。保证恢复阈值低于异常阈值，等级阈值递增。当前默认：

| 参数 | 值 / 含义 |
|---|---|
| highThreshold | 1000，启动异常计时 |
| resetThreshold | 900，清零和恢复 |
| Nano 全开 / 半闭 / 全闭 | 异常启动后按 1000、1400 分档 |
| XIAO 五档 | 1000、1200、1400、1600 分档 |
| levelHysteresis | 40，仅用于已进入等级的下降回差 |

记录的清洁空气基线若已超过 1000，不应继续用默认值做空气结论。换电源、传感器或分压后都应重新标定。ADC 原始值连续 5 秒 ≤2 或 ≥满量程−2 会在预热结束后锁定 `fault=4`；若预热期间已持续 5 秒且结束时仍异常，会立即锁定。这也可能表示气体响应饱和，应先检查环境和接线。

## 验收步骤

1. 用 `nano_demo` 或 `xiao_demo` 验证快速流程，串口应明确打印 DEMO。上电 H1 归位，5 秒预热结束前不得累计异常计时或振动。
2. 使用可控、在 ADC 安全范围内的模拟输入（例如临时电位器）测试阈值，避免用有害气体制造测试环境。传感器正常接线实验与模拟输入逻辑实验分开记录。
3. 指标超过异常阈值，记录 `HIGH_AIR_TIMING` 时间。经过 30 秒后应为 `ALERT`，完成三次 0.5 秒振动，并同时执行闭眼/开眼/回到等级位置。
4. 持续异常，快速模式每 10 秒再提醒。中途将指标降到 ≤900，待滤波值达到条件后立即停止剩余振动、返回 H1；再次异常需重新计满 30 秒。
5. 将指标维持在 900～1000，验证既有异常计时保持；从正常直接进入该区间不应开始计时。
6. 运动中让目标霍尔失效，应在动作开始后 3 秒内停机并锁定；更换目标不得不断延长该预算。短时同时触发两个霍尔应暂停输出，持续冲突应锁定 `fault=1`。
7. 断开 / 饱和 MQ135 输入只用于验证可检测的极端 ADC 故障。若输入悬空落在中间值，软件不一定能发现，不能据此宣称断线诊断完备。
8. 验证完改回 `nano` 或 `xiao`，确认无 DEMO 标识，再做至少一次真实的 30 分钟首报与后续 10 分钟重报验证。

当前自动化检查只能覆盖软件。尚未连接实机，未确认机械位置、供电稳定性、舵机推力、N20 方向和 MQ135 标定值。上电断电会重新开始计时，方案未设计断电续计。
