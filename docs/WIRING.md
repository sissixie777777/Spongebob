# 接线

## 默认：消费表格内的 Nano + SG90

| 器件 | Nano 引脚 / 连接 |
|---|---|
| MQ135 AO | A0 |
| MQ135 VCC / GND | 外部稳压 5V / 共地 |
| A1104 H1 全开 VOUT | D2 |
| A1104 H2 半闭 VOUT | D3 |
| A1104 H3 全闭 VOUT | D4 |
| A1104 VCC / GND | 5V / 共地，按实际封装数据手册确认脚序 |
| 每个 A1104 输出上拉 | 10kΩ 至 5V；代码也启用内部上拉 |
| SG90 信号线 | D9 |
| SG90 电源线 | 外部 5V 母线及共地 |
| 带驱动振动模块 IN | D6，高电平启动 |
| 振动模块 VCC / GND | 外部 5V / 共地 |

Nano 是 5V 控制器，MQ135 AO 可接 A0，前提是输出不超过其供电和 ADC 范围。若保留原方案的分压也可工作，但必须依据实际 ADC 重新标定。不要把 SG90 当 N20 接到 L293D；不要把裸振动电机直接接 GPIO。表格中的振动模块必须确认为高电平有效的带驱动三线模块；若实物不同，应先调整适配代码。

SG90 和 MQ135 从外部电源供电，不通过 Nano GPIO 或板载小电流稳压器供电。外部稳压 5V 输入 Nano 的 5V 引脚，所有 GND 共地。电源模块附近及舵机附近安装表格中的储能电容，注意电解电容极性。Nano USB 与外部 5V 并用是否安全取决于实际兼容板电路；未确认隔离前，烧录时关闭外部电源并断开舵机供电。

表格购买了两节电池，但使用一个**单节电池盒与 1S 电源模块**。按单节电源系统接线，额外电池可作为备用，不能因采购数量为 2 就串联给 1S 模块供电。主体与背包仍仅通过 5V / GND 两根线连接。开关和保护/升压接法需按实际一体电源板的说明确认。

H1→H2→H3 必须沿闭眼方向依次排列，磁铁一次只允许触发一个霍尔。程序不接受同时触发两个霍尔作为正常位置。SG90 的开闭角度默认 30°→150°，只是待标定起点，不能直接保证适合任意连杆。

## 可选：原 README 的 XIAO + N20 + L293D

| 功能 | XIAO 标签 | ESP32S3 GPIO |
|---|---|---|
| MQ135 AO 分压后 | A0 / D0 | 1 |
| H1～H5 | D1～D5 | 2、3、4、5、6 |
| L293D IN1 / IN2 | D6 / D7 | 43 / 44 |
| L293D EN1 | D8 | 7 |
| L293D IN3 振动 | D9 | 8 |

其余 L293D 引脚沿用上游 README：EN2 接 5V，IN4 接 GND，逻辑和电机供电接 5V，四个 GND 脚接共地。MQ135、A1104 的供电为 5V，霍尔输出通过 10kΩ 上拉至 **3.3V**。XIAO 5V 输入按上游说明串肖特基二极管。D8/D9 不与 microSD 共用。

原文 10kΩ 上臂、20kΩ 下臂在输入 5V 时得到约 3.33V，不能作为不超过 3.3V 的保证，且电阻有公差。使用更有余量的分压，例如上臂 20kΩ、下臂 10kΩ，5V 时约 1.67V；确认实际最大输入后重新标定阈值。不要将 5V AO 直接连接 ESP32 ADC。

首次 N20 测试应先脱开连杆，确认归位方向朝 H1；若相反，在 `main.cpp` 切换 `DC_REVERSED`。`MOTOR_PWM=140` 是调试起点，需依据负载、L293D 压降与电机速度调整，并在安全范围内保持 3 秒定位超时。

引脚映射依据 [Seeed 官方说明](https://wiki.seeedstudio.com/xiao_esp32s3_getting_started/)。Servo 库使用定时器，Nano 版本不依赖 D9/D10 的 `analogWrite`；振动使用 D6 的数字高低电平，参见 [Arduino Servo API](https://github.com/arduino-libraries/Servo/blob/master/docs/api.md)。
