POWER

供电原则

  • 推荐使用 5V / 2A USB 电源作为原型主电源。
  • 5V 先进入面包板电源轨，再给 MQ135 / SG90 / 振动模块 供电。
  • OLED 从 ESP32S3 的 3.3V 取电。
  • 所有模块 必须共地。

CHECKLIST

上电前检查

  • 确认舵机红线接 5V，信号线才接 GPIO。
  • 振动模块使用带驱动版本，避免 GPIO 直接带电机。
  • MQ135 模拟输出电压如果过高，需要分压后再进 ESP32S3 ADC。
  • 确认 5V 与 3.3V 没接反，没有短路。
